# suomen_kylat_haku
Selaimessa toimiva hakuohjelma Kansallisarkiston paikkatietoaineistoon *Suomen kylät 1540–1940*. Aineistossa on Suomen vanhat maakirjakylät voudintileistä 1900-luvulle, yhteensä 14 172 kylää. Ohjelmalla voi etsiä kyliä eri tavoin, katsoa kylän pitäjähistorian, avata kylän linkit muihin palveluihin ja kopioida kylän koordinaatit.
